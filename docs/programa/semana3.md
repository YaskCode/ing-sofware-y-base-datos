# Semana 3 — Bases de Datos Inteligentes, DevOps y DevSecOps

## Objetivo
Implementar modelos de persistencia híbridos y automatizar procesos de integración, despliegue y validación de calidad del software.

## Teoría
- Bases de Datos Relacionales
- Bases de Datos NoSQL
- Firestore
- BigQuery
- Bases de Datos Vectoriales
- Diseño de modelos híbridos de datos
- CI/CD
- GitHub Actions
- DevOps y DevSecOps

## Sprint Técnico
Cada equipo implementará la persistencia de datos de su solución, configurará pipelines CI/CD y automatizará pruebas y despliegues básicos.

## Entregable
- Modelo relacional
- Modelo NoSQL
- Configuración Firestore
- Dataset BigQuery
- Pipeline GitHub Actions
- Dockerización de servicios
- Evidencias de despliegue
- Validación de pruebas automáticas

## Guía de trabajo

Vincula cada modelo de persistencia con una necesidad del sistema. Explica la fuente de verdad de cada dato y las exigencias de consistencia, disponibilidad y escalabilidad. Distingue el uso transaccional, documental, analítico y vectorial. Documenta el traslado de datos sintéticos a BigQuery, el control de acceso y cómo reproducir el pipeline.
