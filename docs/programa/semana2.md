# Semana 2 — Arquitectura Cloud-Native y Sistemas Inteligentes

## Objetivo
Diseñar arquitecturas escalables y resilientes basadas en microservicios, servicios cloud-native y sistemas inteligentes orientados a agentes.

## Teoría
- Arquitectura Monolítica vs Microservicios
- Arquitectura Cloud-Native
- Sistemas AI-first
- Serverless Computing
- Docker y Contenedores
- Sistemas Multiagente
- Introducción a MCP (Model Context Protocol)

## Sprint Técnico
Cada equipo definirá la arquitectura de su solución, los componentes principales, servicios, APIs y estructura inicial del backend cloud-native.

## Entregable
- Diagrama de arquitectura
- Diagrama de microservicios
- API contracts
- Dockerfile inicial
- Definición del agente inteligente del equipo
- Arquitectura AI-first

## Guía de trabajo

Distingue estilo arquitectónico, patrón arquitectónico, patrón de diseño y arquitectura de referencia. Justifica los que apliques. Modela límites de servicios, API gateway y un flujo de eventos con productores, consumidores y tratamiento de duplicados. Define contratos con entradas, salidas y errores, y documenta qué herramientas requeriría el agente y dónde se integraría MCP.
