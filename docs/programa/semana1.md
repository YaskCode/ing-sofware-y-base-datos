# Semana 1 — Ingeniería de Software Moderna, Calidad y Diseño IA

## Objetivo
Aplicar principios de ingeniería de software moderna, estándares de calidad y herramientas de IA generativa para el diseño inicial de una plataforma inteligente cloud-native.

## Teoría
- Evolución de la Ingeniería de Software
- AI-Augmented Development
- SWEBOK
- ISO/IEC 25010
- Documentación viva
- Mermaid
- GitHub como entorno de ingeniería colaborativa

## Sprint Técnico
Cada equipo definirá su agente inteligente, historias de usuario, requisitos funcionales y no funcionales, y primeros diagramas del sistema.

## Entregable
- README inicial
- Historias de usuario
- Requisitos funcionales y no funcionales
- Diagramas de CU
- Descripción de los CU
- Evaluación ISO 25010 preliminar

## Guía de trabajo

Compara plataformas similares mediante una matriz funcional y deriva una oportunidad de mejora. Delimita actores, alcance y flujos. Convierte un atributo de calidad en un escenario medible. Relaciona cada historia prioritaria con un requisito y su criterio de aceptación.

Completa la entrega con Gantt, hitos y responsables, registro de riesgos, estimación de costos y factibilidad. Describe el propósito, entradas, herramientas y límites del agente propuesto. Registra las decisiones asistidas por IA y cómo las verificaste.
