| Tema | Lecturas de referencia |
|---|---|

| Arquitectura | Mark Richards y Neal Ford, *Fundamentals of Software Architecture* · Sam Newman, *Building Microservices* |
| Persistencia y DevOps | Martin Kleppmann, *Designing Data-Intensive Applications* · Alex Petrov, *Database Internals* · Gene Kim, Jez Humble, Patrick Debois y John Willis, *The DevOps Handbook* |
| IA y MLOps | Chip Huyen, *Designing Machine Learning Systems* · Noah Gift y Alfredo Deza, *Practical MLOps* · documentación de IA generativa en Google Cloud |
